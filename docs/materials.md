# 平铺资料夹与私有 OSS

资料夹不支持子文件夹。Web 用照片相框、文档纸张卡片展示文件名、类型和大小；支持搜索、分类、最多 20 份逐项上传、失败重试、打开原件、删除确认和资料对话入口。每份文件上限 20 MB。小程序复用同一 API，显示相同风格的平铺卡片；上传仍使用原有单文件选择流程。

支持 JPEG、PNG、WebP、PDF、DOC、DOCX、UTF-8 TXT 和 MD。图片生成最长边 480 像素的 WebP 缩略图并纠正 EXIF 方向；PDF 尽量渲染第一页并记录页数。Word、文本和不能渲染的 PDF 使用简洁纸张图形，不在缩略图中展示正文摘录。所有卡片将类型和大小收在缩略图底部。资料夹为完整页面，顶部保留紧邻的返回、标题与搜索图标，点图标进入独立搜索页，底部玻璃悬浮岛放置全部／照片／文档分类和加号添加入口，列表预留底部空间，小程序适配底部安全区；与主场景一致的灰白毛毡底、无框标题与植物纸页呼应书桌素材，去掉套层面板与封边，不绘制模拟系统胶囊，小程序导航按真实胶囊尺寸留出右侧空间；不提供拖拽上传。原件保持不变。无视觉识别配置时不宣称理解图片；不在预览页提供手动说明编辑。

## 存储与隔离

开启 `MATERIAL_STORAGE=oss` 后，新上传的原件和缩略图存放在：

```
bio-v3/users/<SHA-256(服务端内部用户ID)>/materials/<服务端生成的UUID>/original
bio-v3/users/<SHA-256(服务端内部用户ID)>/materials/<服务端生成的UUID>/thumbnail.webp
```

此目录与 `bio-v3/assets/` 界面素材、Calendar 对象分开。目录哈希不构成权限验证；真正的边界是登录身份和服务端归属检查。

- 对象固定为 private，禁止覆盖，客户端没有 OSS 访问密钥。
- 接口只接受资料 ID；用户 ID 来自认证会话，路径由服务端生成。
- 列表、详情、原件、缩略图、修改、删除及模型读取都限制当前用户。归属不匹配返回 404；未登录返回 401。
- 原件和缩略图经过鉴权接口读取，由服务端从 OSS 获取内容；不返回长期公开 URL，也不允许界面素材 CDN 签名入口访问用户目录。
- Web 图片使用 HttpOnly 登录 Cookie，显式 Bearer 优先；小程序下载图片时携带 Bearer。响应设置 `private, no-store` 和 `nosniff`。
- 只有原件与缩略图都成功保存后才发布元数据。失败会尝试清理本次新对象；删除会先删除 OSS 内容再删除元数据。
- 标题、归属和提取正文等元数据仍保存在现有用户隔离的服务端持久卷。备份必须同时考虑元数据与 OSS 对象；现有文件备份脚本不会复制 OSS 中的原件。

本地开发默认 `MATERIAL_STORAGE=local`；启用账号的 production 环境默认要求 OSS，缺少配置会阻止启动，避免悄悄把新文件存回本地。旧本地资料继续可读，不会因为切换配置而丢失；本次没有自动迁移旧资料。若元数据声明对象存于 OSS 而密钥未配置，明确报错，不降级为其他用户或目录。

## 部署配置

仅在服务器私有环境文件中设置：

```
MATERIAL_STORAGE=oss
MATERIAL_OSS_REGION=oss-cn-beijing
MATERIAL_OSS_BUCKET=calendar-images
MATERIAL_OSS_ACCESS_KEY_ID=<服务端密钥>
MATERIAL_OSS_ACCESS_KEY_SECRET=<服务端密钥>
```

当前通过 Calendar 的服务端配置完成连通性验证，未创建新的 RAM 身份或修改桶策略。后续配置独立 RAM 凭证时，权限仅需此桶 `bio-v3/users/*` 下的 GetObject、PutObject 和 DeleteObject。无需允许客户端列举桶，不关闭桶的公共访问阻止策略。应用内按用户隔离仍然必须执行，RAM 前缀限制不能替代它。

## 验证

`materials.test.mjs` 覆盖真实 PDF/DOC/DOCX 文件、缩略图和原件保留；`materials-oss.test.mjs` 覆盖私有路径、隔离、重启读取、部分失败清理；账号数据库测试覆盖原件与缩略图的 Cookie/Bearer 权限边界。

真实 OSS 的显式验收（只创建合成用户文件，结束后清理）：

```sh
MATERIAL_OSS_LIVE_EVAL=true node apps/api/test/materials-oss-live.mjs
```

需要上述 OSS 配置。验证实际上传/读取、跨用户拒绝和匿名 OSS URL 返回 403，不使用真实用户文件。

分类高亮使用同一玻璃块滑动并轻微回弹；列表先退场，再按序进入，不展示独立数量行。快速切换只提交最后一次筛选，页面退出清理定时器。减少动态效果偏好下关闭位移与回弹；不支持背景模糊时使用可读的浅色底。

搜索页只显示文件名匹配结果，默认不显示全部资料；停止输入 1 秒后筛选，键盘搜索立即执行。新输入取消旧定时器，清空、返回和卸载清理等待；Web 中文输入法合成期间不触发搜索。搜索覆盖所有分类，使用已鉴权加载的当前用户列表，不随按键发起网络请求。

搜索输入采用透明底与细灰色底线，移除通用绿色焦点框；资料卡、照片边框与玻璃导航统一降低黄色饱和度，保留毛毡纹理。

文件打开后进入独立全屏预览，返回直接回资料夹；顶部显示文件名与删除入口。图片按原比例展示原图，PDF 使用真实首页预览，打开原件查看完整文件，Word／文本显示提取文字并标注文字预览；小程序 PDF 显示首页并可用原生查看原件。预览页不提供名称与说明编辑，底部用令狸半身形象搭配“和令狸聊聊”入口，删除需确认，成功后移除列表项。

聊天入口使用独立生成的令狸透明半身素材 `assets/materials/lingli-chat.webp`，不再裁切动画帧；删除入口为带无障碍名称的垃圾桶图标，保留确认流程。

资料卡长按显示“预览／和令狸聊聊／删除”，删除需二次确认；Web 同时支持右键与 Shift+F10。移动超过 10px 或触摸取消会撤销 Web 长按，长按松手不会误打开预览；小程序使用原生 longpress 触发自定义菜单。两端菜单均以略微倾斜的缩略图和文件名卡片悬浮在上方，下方预览、聊天、删除、取消等宽居中，背景轻微虚化。搜索结果复用同样的操作。
