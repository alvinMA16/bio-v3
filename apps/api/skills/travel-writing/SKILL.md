# 游记写作

让读者跟着叙述重新经历这趟旅程，也让用户日后重读时，找回可能已经忘记的过程和细节。默认采用具体、鲜活、有叙事起伏的写法，给重要经历充分篇幅。用户指定的用途、体裁、风格和修改范围优先；讨论方案时只提建议，要求成文时才通过文稿工具交付文章。

## 选材与重心

先读任务所需的原始讲述与已有文稿。历史摘要用于定位素材，不代替可取得的原文。根据用户想表达什么决定文章重心，不因为出现旅行地名就自动采用游记体裁；若目的明确属于人生或关系回忆，改用相应技能。

选材时同时关注事件的过程和细节的记忆价值。找出讲述中原先的预期、实际发生的变化、人物如何应对以及后来怎样发展；凡是已有素材里的波折、误会、反差或意外，不能在整理中压成一句结果。路线帮助读者理解行进，不决定每段篇幅；根据原始讲述分配详略，避免沿用已有短稿的删减而继续丢失素材。

保留能够让人认出当时情境的小细节，包括用户提供的具体物件、动作、说话方式、感官印象及人与人之间的反应。细节即使不推动情节，只要能唤回那次经历，也有保留价值。删掉重复表达，而不是删掉事情发生的过程；不要将丰富经历压缩为“很美”“很开心”等概括。

叙事起伏来自素材中实际发生的变化，不预设每段都要有冲突或反转。平静的小事可以通过观察和相处细节写得鲜活，不升级为惊险经历。素材适合几个独立片段时，可以写成片段式游记，不强求覆盖全程。

## 结构与表达

按照素材选择行进顺序、代表性场景或主题串联。交代足够的时间、地点与人物背景，让没听过聊天的人也能读懂；重排叙述顺序不能改变真实事件的先后。重要事件让读者看见事情如何一步步发生，不一开头便用结果概括掉整个过程，也不靠隐瞒已知事实或添加悬念话术制造曲折。

重要场景使用已有动作、可靠的对话、观察和体验展开，保留变化发生前后的衔接，以及用户当时已表达的期待、判断与反应。过程链条以素材为限，不机械凑齐固定步骤。没有细节的转场可以简洁交代；交通、住宿等日常环节若承载了难忘的经过，同样充分展开，不能因为它们不是景点就略去。

让场景与简短交代相间，为重要时刻留出停顿和篇幅，避免每个地点都用相同长度、相同句式依次介绍。只有与这次经历有关时才纳入目的地背景，不用景点介绍填补私人体验，更不把外部资料写成用户亲眼所见。

保留用户的口吻、幽默和感受分寸，修掉口头重复，而非统一换成抒情腔。篇幅服从素材密度与用途，不靠形容词扩写。开头选择值得进入的具体切口，结尾停在有依据的画面、事件或感受上，不固定使用行程总览和旅行感悟。

## 缺口与交付

遵守基础真实性规则；生动来自对真实素材的充分呈现，不能补造感官细节、直接引语、心理活动或事件转折。发现原文只交代结果、重要过程缺失时，先查已有资料；若补足这一处确实能还原关键经历，可以围绕一个具体时刻自然追问，不连续采访。用户要求直接成稿时，用现有素材写成成立的短篇或片段，不以猜测补足过程。

交付前回到原始讲述逐段对照：真实的波折和人物应对是否被压成结果，能唤起回忆的小细节是否因追求简洁而丢失，重要场景是否有足够篇幅，路线是否淹没经历，人物是否只剩称谓，语言是否仍属于用户，以及是否混入无来源的描写与感悟。原文已有而成稿遗漏的重要过程与细节应补回；素材确实没有的内容不补造。先修订再交付，不把检查过程写进正文。

长文分批保存前先形成整体结构，保存有意义的开头后继续完成全文，不把行程摘要或提纲当成完成稿。口头说明保持简短，文章长度独立服从任务。
