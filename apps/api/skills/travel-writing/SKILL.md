# 游记写作

让读者读到这个人在这趟旅程中的独特经历。用户指定的用途、体裁、风格和修改范围优先；讨论方案时只提建议，要求成文时才通过文稿工具交付文章。

## 选材与重心

先读任务所需的原始讲述与已有文稿。历史摘要用于定位素材，不代替可取得的原文。根据用户想表达什么决定文章重心，不因为出现旅行地名就自动采用游记体裁；若目的明确属于人生或关系回忆，改用相应技能。

选择最值得留下的见闻、相遇、旅途插曲或观察，围绕它们安排详略。路线可以帮助读者理解行进，但不要让地点清单决定每段篇幅。保留那些使这趟旅行区别于其他旅行的具体细节、人物互动和用户自己的说法，不将丰富经历压缩为“很美”“很开心”等概括。

旅行的吸引力可以来自日常观察和小事，不必人为制造意外、冲突或转变。素材适合几个独立片段时，可以写成片段式游记，不强求覆盖全程。

## 结构与表达

按照素材选择行进顺序、代表性场景或主题串联。交代足够的时间、地点与人物背景，让没听过聊天的人也能读懂；重排叙述顺序不能改变真实事件的先后。

重要场景使用已有动作、对话、观察和体验展开，普通交通、住宿和转场按其叙事作用简洁处理。只有与这次经历有关时才纳入目的地背景，不用景点介绍填补私人体验，更不把外部资料写成用户亲眼所见。

保留用户的口吻、幽默和感受分寸，修掉口头重复，而非统一换成抒情腔。篇幅服从素材密度与用途，不靠形容词扩写。开头选择值得进入的具体切口，结尾停在有依据的画面、事件或感受上，不固定使用行程总览和旅行感悟。

## 缺口与交付

遵守基础真实性规则；场景描写只能展开已知素材，不能补造感官细节或直接引语。缺口先查已有资料；若确实影响文章理解或重心，再围绕一个重要点向用户求证，不连续采访。用户要求直接成稿时，用现有素材写成成立的短篇或片段。

交付前对照原文检查：是否保留独特细节、重要场景是否有足够篇幅、路线是否淹没经历、人物是否只剩称谓、语言是否仍属于用户，以及是否混入无来源的描写与感悟。先修订再交付，不把检查过程写进正文。

长文分批保存前先形成整体结构，保存有意义的开头后继续完成全文，不把行程摘要或提纲当成完成稿。口头说明保持简短，文章长度独立服从任务。
